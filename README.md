## About

Owlin is a lightweight desktop mod menu for Euro Truck Simulator 2. It provides a clean interface, plugin-based tools, simple setup, and regular updates.

## Features

### :gear: Mod Menu
* Speed Hack
* No Damage
* Infinite Fuel
* Auto update
### :unlock: DLC Bypass
* Access DLC content without owning DLCs
### :shield: Guard
* HWID Spoofer protection against hardware-based bans
