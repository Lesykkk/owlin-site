## About

Owlin is a lightweight desktop mod menu for Euro Truck Simulator 2 and American Truck Simulator, including multiplayer clients. It provides a clean interface, plugin-based tools, simple setup, and regular updates.

## Features

### :gear: Essentials (free)
* No Damage
* Infinite Fuel
* Stability
* Suspension and engine tools
* NoCLip (No collisions)

### :shield: Spoofer
* HWID ban protection & bypass
* Own controls and a configurable overlay

### :unlock: DLC Unlock
* Access DLC content without owning DLCs
* Managed directly from the Owlin interface
